# 🌍 WanderLust — Escape the Ordinary!

✨ *Your next adventure starts here.*

WanderLust is a travel and accommodation website inspired by Airbnb, built to make discovering amazing places easier and more exciting. 🚀

I'm building this project step by step while exploring the world of web development.

## ⚡ Tech Stack

- 🟢 **Node.js** — Powering the backend
- 🚂 **Express.js** — Handling routes and requests
- 🍃 **MongoDB** — Storing application data
- 🎨 **HTML & CSS** — Bringing the website to life
- ⚡ **JavaScript** — Making things work
